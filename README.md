App Idea:
I'd like to build a 'gratitude jar' app. It's a simple concept: there's a jar and a notepad that users can take a leaf off of, write something they are grateful for (or a prayer, etc.) and there's a mini animation that shows the notes going into the jar when they put it in. The app has a feature to pick out a random note from the jar so the user can readand be reminded of something great ("I will remember the deeds of the Lord; yes, I will remember your wonders of old." - Psalm 77:11), and is also connected to a backend database that stores all the notes written in the jar, their dates, times, etc. – users can browse this (through a prettier front-end) to see notes that they've written in the past. There should also be options to customize/ change the background, tailoring to the users preferences.
